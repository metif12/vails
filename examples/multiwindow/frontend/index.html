Cross-window ping

Asks V to send one event to the other window by label. The proof is that the status line over there changes while this one says only “sent” — and that this window's own line never moves.

Broadcast

Sends the same event to every window, including this one. If the routing were wrong in the “everything goes to one window” direction, this page would be the one that misses it.
